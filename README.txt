PAST LIVES EDITORIAL

Unzip this folder and open index.html in a web browser.
Keep index.html, styles.css, script.js, and assets together.

Includes the smaller interactive illustration, first ECO banner, and Group 9 second advertisement.
Hover over illustration panels to switch images. Tap or use Tab and Enter on a keyboard.
The trailer thumbnail links to YouTube. The thumbnail is bundled locally.

styles.css contains the saved article styling and custom layout rules.
script.js contains the illustration interaction.
assets contains the images and other embedded resources extracted from the saved page.
